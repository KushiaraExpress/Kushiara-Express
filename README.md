# কুশিয়ারা এক্সপ্রেস (KUSHIARA EXPRESS)

**সত্যের পথে, মানুষের সাথে।** — সিলেট, গোলাপগঞ্জ, বাংলাদেশ ও বিশ্বের সর্বশেষ সংবাদের জন্য নির্মিত একটি পূর্ণাঙ্গ, প্রফেশনাল ও স্কেলেবল বাংলা ডিজিটাল নিউজ পোর্টাল।

## মূল বৈশিষ্ট্যসমূহ

- **প্রিমিয়াম নিউজ পোর্টাল (Public Portal)**:
  - ব্রেকিং নিউজ টিকার (গতি, রঙ ও সময় নিয়ন্ত্রণযোগ্য)
  - বাংলা ও ইংরেজি ক্যালেন্ডার তারিখসহ আধুনিক মাস্টহেড
  - লিড নিউজ, টপ হেডলাইন, সর্বশেষ, জাতীয়, আন্তর্জাতিক, সিলেট, গোলাপগঞ্জ, রাজনীতি, অর্থনীতি, শিক্ষা, প্রযুক্তি, খেলাধুলা, বিনোদন, জীবনযাপন, ধর্ম ও মতামত সেকশন
  - ফটো গ্যালারি, ভিডিও সংবাদ, সর্বাধিক পঠিত ও সম্পাদকীয় পছন্দ
  - তাৎক্ষণিক অনুসন্ধান (Search), নিউজলেটার সাবস্ক্রিপশন ও রিলেটেড নিউজ
- **সুরক্ষিত সুপার অ্যাডমিন ড্যাশবোর্ড (`/admin`)**:
  - শুধুমাত্র অনুমোদিত একজন সুপার অ্যাডমিনের জন্য সংরক্ষিত লগইন (পাবলিক রেজিস্ট্রেশন নিষ্ক্রিয়)
  - ১৯টি পূর্ণাঙ্গ মডিউল: ড্যাশবোর্ড স্ট্যাটাস, রিচ টেক্সট নিউজ এডিটর, ড্রাফট/শিডিউল/পাবলিশ, ব্রেকিং নিউজ ম্যানেজার, ক্যাটাগরি ও সাবক্যাটাগরি, গ্যালারি, ভিডিও, Adsterra অ্যাড ম্যানেজার, হোমপেজ কাস্টমাইজার, নেভিগেশন ম্যানেজার, এসইও, সোশ্যাল মিডিয়া, ওয়েবসাইট সেটিংস, অ্যাক্টিভিটি লগ, ব্যাকআপ ও এক্সপোর্ট, ডিপ্লয়মেন্ট ও আপডেট প্যানেল
- **Adsterra বিজ্ঞাপন ম্যানেজার**:
  - Popunder (ফ্রিকোয়েন্সি লিমিটসহ), Social Bar এবং ১০টি ভিন্ন ব্যানার প্লেসমেন্ট
  - ডেস্কটপ ও মোবাইল ভিজিবিলিটি এবং শিডিউল নিয়ন্ত্রণ
- **Facebook OpenGraph ও SEO ইঞ্জিন**:
  - সার্ভার-সাইড OpenGraph (`og:title`, `og:description`, `og:image`, `og:url`) এবং Twitter Card ইনজেকশন (`server.ts` এবং `netlify/functions/og-meta.ts`)
  - `NewsArticle`, `NewsMediaOrganization` ও `BreadcrumbList` JSON-LD স্কিমা
  - ডাইনামিক `/sitemap.xml` ও `robots.txt`

## দ্রুত শুরু (Local Development)

```bash
npm install
cp .env.example .env
# .env ফাইলে আপনার Supabase প্রজেক্টের তথ্য দিন (অথবা প্রিভিউ SQLite মোডে টেস্ট করুন)
npm run dev
```

বিস্তারিত ডিপ্লয়মেন্ট, Supabase SQL, RLS এবং Netlify নির্দেশিকার জন্য [`DEPLOYMENT.md`](./DEPLOYMENT.md) দেখুন।
